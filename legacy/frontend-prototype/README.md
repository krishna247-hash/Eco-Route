# Legacy frontend prototype

The original single-app Next.js pages and components from before the
monorepo rebuild (Phase 1). They import from a `src/lib/` module
(`lib/types`, `lib/carbon/*`, `lib/optimizer/pareto`, `lib/data/destinations`,
`lib/ai/explain`) that documented itself in the old root README but was
never actually committed — so none of this ever built. Kept for
reference only; the running app's frontend is `frontend/`.
